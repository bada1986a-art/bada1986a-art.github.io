# 우리 가족 기록장

가족의 하루를 한 곳에 모으는 기록장입니다. 홈·루틴·식사·일정·건강·칭찬·용돈·메모를 한 화면에서
볼 수 있고, 아이 루틴을 마치면 치와와 도장이 찍힙니다.

기록은 서버로 보내지 않습니다. 연 브라우저의 `localStorage`에만 저장되고, 기기를 바꿀 때는
설정의 백업/복원(JSON 파일)으로 옮깁니다.

## 휴대폰에 앱처럼 설치하기 (Android Chrome)

1. <https://bada1986a-art.github.io/> 를 엽니다.
2. 오른쪽 위 ⋮ 메뉴 → **앱 설치** (또는 **홈 화면에 추가**).
3. 홈 화면의 치와와 아이콘으로 바로 열립니다. 설치하면 오프라인에서도 화면이 열립니다.

iPhone은 Safari에서 열고 공유 → **홈 화면에 추가**를 누르면 됩니다.

## 파일

- `index.html` — 앱 전체 (마크업·스타일·스크립트가 한 파일에 들어 있습니다)
- `manifest.json` — 앱 이름, 아이콘, 시작 주소
- `sw.js` — 오프라인 캐시 서비스 워커
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — 앱 아이콘
- `tools/make_icons.py` — 아이콘을 다시 만들 때 쓰는 스크립트
